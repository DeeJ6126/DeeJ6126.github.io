# R基础

## 1.1 用户界面

**控制台**

- 运行结果前面的数字，如"[1]"，代表输出结果顺序
- 冒号运算符(:)表示返回两个整数值之间的所有整数

在命令行里运行得到的结果不会保存在计算机内存里，如果要多次使用，需要保存起来。该操作在R中称作 **创建一个R对象(object)**

## 1.2 对象

在R中存储额度数据就是一个**R对象**

```r
die <- 1:6

die
```

**R命名**

- 不能以数字开头

- 不能有特殊符号

- 区分大小写

如果想查看试用了哪些R对象，可以使用

```r
ls()
```

运算方面

- die作为一个向量，R 使用 **元素方式执行**

```r
die - 1
```

- 如果运算中涉及多个向量，则 R 会将向量排成以后并执行一系列单独运算。

```r
die * die
```

- 如果两个向量长度不相等，R会在短向量上重复，直到长度与长向量一致，再执行运算。该行为称作 **向量循环**

```r
1 : 4

die + 1 : 4 
# 本质是die + [1,2,3,4,1,2]
```

**矩阵乘法**

```r
die %*% die # 1+4+9+16+25+36

die %o% die
```

为了让这个骰子掷起来，可以编写一个 **函数 function**

## 1.3 函数

传递到函数的数据称作 **参数argument**，可以使用一些简单函数，例如

```r
round(3.14) # 四舍五入

factorial(3) # 阶乘
```

为了掷骰子，可以使用sample函数，共2参数：

- 向量x + 数字size

- 代表从 x 中抽取 size 个元素

```r
sample(x = die, size = 1)

sample(x = die, size = 2, replace = TRUE) # 表示可放回抽样
```

**注意点**

- 在给函数的参数赋值的时候，要用 `=` 而不是 `<-`

- 一般来说，可以省略R函数第一个参数的名称，如sample(die, size = 1)

如果不清楚函数的参数，可以使用

```r
args(round)
```

其中，`digits = 0` 代表该参数具有默认值，即默认保留0位小数

## 1.4 自定义函数

若要模拟掷骰子2次后得到的和，可以使用自定义函数`roll()` 实现下面的过程

```r
die <- 1:6
dice <- sample(die, size = 2, replace = TRUE)
sum(dice)
```

R函数包含三部分

- 函数名

- 程序主题

- 参数集合

具体需要调用`function()`函数，并在后面加大括号。function的作用是将大括号的所有代码构建出一个函数，并能在小括号中放参数，并能够设定默认值

```r
roll <- function( # roll 为函数名
    bones = 1:6 # 小括号：参数集合
    ){
  die <- bones
  dice <- sample(die, size = 2, replace = TRUE)
  sum(dice)
} # 大括号：程序主体

roll()
```

# 2. R包

可以使用`install.packages()` 命令快捷下载包

```r
install.packages("ggplot2")
```

安装之后，包内函数并非立即可用，只是把R包装在了硬盘上。如果需要使用，则要命令`library()` 来加载包。

```r
library("ggplot2")
```

每个包只需要安装一次，但在新的R会话中，需要重新用`library` 加载一次。

如果想创建数值向量，可以使用`c()`代表**连接concatenate**

如果要使用ggplot，需要将所有数据放在数据框里，靠列名来使用。这样图和数据绑定，后续加图层、映射等都挺方便，经典结构如

```r
ggplot(
  iris, # 画布
  aes(  # 坐标映射
    x = Sepal.Length,
    y = Sepal.Width,
    color = Species # 按物种名着色
    )
  ) +
  geom_point(size = 1) + # 散点图，大小为2
  labs(title = "鸢尾花数据") + # 标题
  theme_classic() # 白底主题
```
