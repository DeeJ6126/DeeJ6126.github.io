### 全连接到卷积

全连接处理图像输入弊端
+ 空间信息丢失
+ 参数量爆炸

设
+ 图像像素索引为$[\mathsf{X}]_{i, j, k}$
+ 卷积核为$[\mathsf{V}]_{a,b,c}$，或称为滤波器，其中参数可学习
+ 隐藏表示为$\mathbf{H}$

卷积神经网络通常是由四种层构成：
+ 卷积层
+ 激活函数层（比如RELU）
+ 池化层
+ 全连接层。
最常见的形式就是将一些卷积层和激活层放在一起，其后紧跟池化层，然后重复如此直到图像在空间上被缩小到一个足够小的尺寸，在某个地方过渡成成全连接层，如下图所示：

#### 不变性

+ 平移不变性 translation invariance
  + 无论检测对象位于何处位置，神经网络前几层应对相同图像区域有相似的反应
  + 且可以使用相同权重
  + $\mathsf{V}$和$\mathbf{U}$实际上不依赖于$(i, j)$的值，即$[\mathsf{V}]_{i, j, a, b} = [\mathbf{V}]_{a, b}$
+ 局部性 locality
  + 神经网络前几层应该只探索局部区域，最终聚合局部特征

![alt text](img/CNN_1.png)

#### 通道

图像往往是三维张量，包含三个通道，即三种原色，shape为$(3, H, W)$。因此，隐藏H最好也采用三维张量。

换句话说，对于每一个空间位置，应该用一组**隐藏**表示，类似于一些互相堆叠的二维网格，想象成一系列具有二维张量的通道。这些通道也比称为**特征映射**

每个通道（可理解为每个二维张量）提供一组空间化学习特征，例如一些识别边缘，一些识别纹理

### 卷积操作

#### 相关概念

**卷积计算**

![二维互相关运算。阴影部分是第一个输出元素，以及用于计算输出的输入张量元素和核张量元素：$0\times0+1\times1+3\times2+4\times3=19$.](img/correlation.svg)

**卷积层**

卷积层通过多个卷积核的组合来提取输入数据的不同特征。每个卷积核负责提取特定类型的特征，卷积层则将这些特征整合在一起，形成更高层次的特征表示。

控制卷积层的几个超参数：
+ **深度**（depth）
  + 相当于通道数
  + 深度 Depth指使用的卷积核的数量，每个卷积核在输入图像中检测一些不同的特征。
  + 举例来说，如果第一个卷积层的输入是原始图像，那么在深度维度上的不同神经元将可能被不同方向的边界，或者是颜色斑点激活。
![alt text](img/CNN-2.png)
+ **步长**（stride）
  + 步长  Stride是指卷积核在输入图像上每次滑动的像素距离。
  + 包含垂直和水平，但通常只讨论水平
  ![alt text](img/CNN-3.png)
+ **填充**（padding）
  + 在卷积过程中，图像边缘的像素参与计算的次数远少于中心像素，且每次卷积都会导致输出尺寸缩小。
  + 为了解决这个问题，我们在输入图像的四周补上一圈额外的像素（通常补0，称为Zero-padding）。
  ![带填充的二维互相关。](img/conv-pad.svg)
+ **偏置**（bias）
  + 与全连接网络的隐藏层类似，卷积层中的每一个卷积核都配有一个可学习的偏置参数 b。
  + 在完成加权求和后，系统会给输出特征图的每一个元素统一加上这个偏置值。

**感受野**
+ 生物里，神经元只感知局部特征而非全局
+ 尺寸
  + 对于单个卷积核，感知野等同于其尺寸 K。
  + 对于L层尺寸为K 的卷积核，感知野等于 1+L*(K-1)。
![alt text](img/CNN-4.png)

**权重共享**
假设：如果一个特征在计算某个空间位置(x,y)的时候有用，那么它在计算另一个不同位置(x2,y2)的时候也有用。基于这个假设，可以显著地减少参数数量：在同一卷积层中，一个卷积核负责扫描整张图像，其权重参数在所有滑动位置保持不变。

![alt text](img/CNN-5.png)

### 多输入多输出通道

#### 多输入通道

卷积核的输入通道数应当与输入的通道数一致：
+ 即，若输入的通道数为$C_{in}$，则卷积核输入通道数也为$C_{in}$
+ 若$C_{in} = 1$，则可以把卷积核看做形状为$K_H \times K_w$的二维张量
+ 若$C_{in} > 1$，则每个输入通道都包含形状为$K_H \times K_w$的张量，连接在一起得到$C_{in} \times K_H \times K_w$的卷积核

由于通道数相同，因此可以对输入和卷积核的每个通道输入的二维张量进行卷积运算，再求和（即将$C_{in}$的结果相加）得到二维张量

![两个输入通道的互相关计算。](img/conv-multi-in.svg)

#### 多输出通道

随着网络层数加深，往往会增加输出通道的维数。可将每个通道看做对不同特征的相应。

用$C_{in}$和$C_{out}$表示输入和输出通道的数目，用$K_H$和$K_w$表示卷积核的高度和宽度。

为了获得多个通道的输出，可以为每个输出通道创建一个形状为$C_{in} \times K_H \times K_w$的卷积核张量，这样卷积核的形状就是$C_{out} \times C_{in} \times K_H \times K_w$。在卷积运算中，每个输出通道先获取所有输入通道，再以对应该输出通道的卷积核计算出结果

#### 1 x 1 卷积

+ 即 $K_H = K_w = 1$
+ 失去了卷积层特有的能力：识别相邻元素间相互作用的能力
+ 可以看做在每个像素位置应用的全连接层
  + 将$C_{in}$个输入值转换成$C_{out}$个输出值
  + 权重维度为$C_{in} \times C_{out}$，再额外加一个偏置

### 总结

+ 输入尺度：$C_{in} \times H \times W$
+ 超参数：	
  + 卷积核尺度：$K_H \times K_w$
  + 深度：$C_{out}$
  + 填充：$P$
  + 步长：$S$

+ 权重矩阵（参数量）： $C_{out} x C_{in} x K_H x K_w$
+ 偏置向量 b： $C_{out}$
+ 输出尺度： $C_{out} \times H' \times W'$

### 池化/汇聚层

**目的**
+ 降低卷积层对位置的敏感性
  + 检测较底层的特征时，希望特征能保持平移不变性，移动几个像素后结果也应该一致
+ 降低对空间降采样表示的敏感性
  + 该任务通常和全局图像有关，所以最后一层神经元应该对整个输入的全局敏感

**形式**
+ 最大池化
+ 平均池化
+ L2范数池化
+ 随机池化


与卷积运算类似，同样具有填充、步长等参数，同样可以有多个通道

### 经典模型

#### LeNet

最早发布的CNN之一，两部分组成

+ 卷积编码器：两个卷积层
+ 全连接层密集块：三个全连接层
![LeNet中的数据流。输入是手写数字，输出为10种可能结果的概率。](img/lenet.svg)

#### AlexNEt

第一个在大规模视觉竞赛中击败传统计算机视觉模型的大型神经网络

+ 五层（卷积+池化层）
+ 3 层全连接层
+ 输入尺度为 3 x 224 x 224。

![alt text](img/AlexNet.png)

**创新点**
+ 更深的神经网络结构
  + 以更好学习数据集的特征，提高分类精度
+ 使用ReLU激活函数，而非传统的sigmoid和tanh
  + 保持计算速度的同时，有效解决梯度消失的问题
+ 局部相应归一化：LRN
  + 卷积层中，每个卷积核对应一个特征图，LRN对这些特征图进行**归一化**，避免过拟合
+ 应用数据增强和Dropout
  + 数据增强：对图像进行旋转，翻转等变换，增加数据多样性，提高泛化能力
+ 分布式训练
  + 将卷积层和全连接层放在不同GPU上并行运算
  + 加快训练速度

#### VGG

+ 设计动机
  + 用更小的卷积核，堆更深的网络
+ 架构特点
  + 统一 3 x 3 卷积
    + 3个 3 x 3 和1个 7 x 7的感受野相同
    + 3个3 x 3的参数更少，层数更多，非线性更多
  + 步长为1
  + 池化：2 x 2，步长为2
  + 多个卷积后 → 一个池化
+ 优点
  + 结构简单、规则
  + 易于复现和迁移
  + 成为“特征提取器”的标准骨架
![alt text](img/VGG.png)

#### GoogLeNet

+ 核心思想
  + 使用不同大小的卷积核组合
+ Inception模块组合：不同尺度特征同时提取，网络自己决定“用哪个”
  + 1 x 1卷积
    + 用于降维，减少参数数量
    + 实现更深层、高效的架构
  + 可以融合不同尺度的特征信息
+ 全局平均池化
  + 不再像传统CNN那样使用全连接层
  + 显著减少模型参数量
  + 减轻过拟合问题
+ 辅助分类器
  + 解决梯度消失问题
  + 仅在训练期间激活，用于**辅助训练**

![alt text](img/GoogLeNet.png)

#### ResNet

+ 事实
  + 深模型比浅模型有更强表示能力
  + 但实际表现不如浅模型
+ 推断
  + 深模型难以优化
+ 解决方案：使用网络拟合残差 $F(x) = H(x) - x$，而不是直接拟合 $H(x)$。
  + 使用网络层来拟合**残差映射**（即$f(x)-x$），可以理解为输出与输入的差距
  + 而不是直接尝试拟合理想映射（即$f(x)$），可以理解为把输入变成输出

![alt text](img/residual-block.svg)

**整体架构**
+ 堆叠残差模块
+ 每一个残差块都是2层 3x3 的卷积
+ 最后先进行全局平均池化，然后全连接
