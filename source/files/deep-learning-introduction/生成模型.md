### 背景

**图像生成**

+ 无条件生成：将无意义的**随机噪声**转成清晰图像
+ 条件生成：根据 **条件** 引导，生成特定图像

**图像矩阵表示**

在计算机底层中，图像表示为H (高度)× W (宽度) × C (通道数) 的张量矩阵

**噪声与结构化图像**

如果不能捕捉到图像中各像素的组合规律（例如完全从随机分布中取值），最终得到的图像只能是没有意义的噪声图像。

因此，要生成有意义的图像，必须学习图像中各像素间的复杂关系

存在一个**真实图像在高维空间中客观存在的概率分布**$p_{data}$ ，如果能够学习到这个分布，在图像生成时让每一个像素都从中采样，就能让生成图像与现实中的图像具备相似的结构特征（如边缘、纹理和语义）

**图像分布的近似**

但图像分布的**形式未知**，**维度高**且**结构复杂**，往往不可直接求解

但可以训练一个神经网络模型 $p_\theta$去拟合$p_{data}$。模型根据大量图像优化参数，贴近复杂的图像分布

![alt text](img/generative-1.png)

随着训练进行，模型分布$p_\theta$与图像分布$p_{data}$会越来越接近，图像也会越来越真实

现如今，一共有四种常见的生成式模型架构

### 变分自编码器（Variational Autoencoder, VAE）

**图像生成难点**

图像分布在高维空间分布稀疏，只能通过降维来解决，即高维的像素空间映射到低维的特征空间。不仅可以简化运算，还可以捕捉到数据中最本质、关键的结构信息

#### 模型架构

自编码器是基于降维的无监督学习模型，通过神经网络实现图像的压缩和重构。核心思想是用低维特征向量表示原本的高位图像样本，再从潜空间中重构出接近原始图像的输出。

+ Encoder
  + 多层神经网络
  + 下采样
    + 大图变成小向量
    + 空间尺寸被压缩
    + 通道数增加
  + 实现 图像数据 -> 潜空间低维特征 映射
+ Decoder
  + 多层神经网络
  + 上采样
    + 小向量恢复成大图
    + 空间尺寸放大
    + 通道数减少
  + 实现 潜空间低维特征 -> 图像数据 的重建
+ Code Layer
  + 最后输出隐空间向量的那层，也叫 latent layer
  + 记录图像中的关键特征

#### 训练流程

+ 目标：让Decoder重构的图像与原图相似
+ 方法：通过降低 重建损失 + KL散度，让模型学会打包和解包图像信息，并学会生成图像
  + **重建损失**
    + 衡量解码后的图片和原始图片相似度,
    + $Loss = (output_pixel - input_pixel)^2$
  + **KL散度**
    + 衡量两个概率分布之间的差距
    + 能够**限制概率分布不退化为点**，中间采样也能有合理的图像，也是与AE的区别
+ 图像生成
  + 对于Encoder编码的隐空间向量，Decoder可以重建出对应的图像
  + 不过，对于一个从未在训练过程中出现的隐变量z，Decoder能生成对应含义的图像吗？

#### 样本级对应与分布级对应

+ Decoder遇到新z时，往往生成无意义噪声图像
  + Decoder只记住z与图像关系，无泛化性
  + 训练图像在隐空间中被映射成孤立、不连续的离散点，点与点之间缺乏过渡
+ 破局方法：样本级对应 -> 分布级对应
  + 样本级对应
    + 一个点对应一张图像
    + 稍微偏移图像就崩溃
  + 分布级对应
    + 一个分步对应一类相似图像
    + 稍微偏移图像只会微小改变
+ VAE的核心思想
  + 不让Encoder输出固定向量，而是输出一个概率分布
  + 将图像分布 $p_{data}$ 映射到一个高斯分布，因此Encoder编码得到的是均值与方差

### 扩散模型（Diffusion Model）

#### 概述

+ 前向过程：图像加噪得到噪声，趋近高斯分布
+ 反向过程：多步去噪，还原图像信息，生成图像

#### 去噪模型设计

+ 流程：根据t步图像 $x_t$ 与时间 $t$ ，经去噪模型 $f_\theta(x_t, t)$ 后得到 $t-1$ 步图像 $x_{t-1}$
+ 思路：先预测噪声后再去除，因为噪声遵从高斯分布，学习难度低

![alt text](img/DM-1.png)

#### 去噪模型训练

为了在去噪时预测两步的噪声，模型需要在训练时学习两步之间的噪声

+ 想法1：加噪过程中，**按顺序**加入每步噪声时，模型同时学习预测噪声
  + 无法打乱样本数据
+ 想法2：采用随机时间步训练，打乱顺序
  + 得加噪$t$次才能得到训练数据——$x_{t-1}$和$x_t$
+ 最终想法：单步加噪得到训练数据 $x_t$
  + 递归加噪过程
    + $q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1 - \beta_t} x_{t-1}, \beta_t \mathbf{I})$
    + $\beta_t$为噪声强度
  + 单步加噪得到训练数据$x_t$
    + $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$
    + $\bar{\alpha}_t = \prod_{i=1}^t \alpha_i, \quad \alpha_t = 1 - \beta_t$
  + 去噪过程
    + $p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))$
  + 损失函数
    + $L = \mathbb{E}_{t, x_0, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t) \|^2 \right]$
+ 训练流程：
  1. 随机采样图像$x_0$, 噪声$\epsilon$ 和时间 $t$
  2. 单步加噪得到噪声图 $x_t$
  3. 学习预测 $x_0$ 与 $x_t$ 之间的**总**噪声

![alt text](img/DM-2.png)

#### 去噪模型推理

1. 给定 t 和 $x_t$，预测噪声并减去
2. DDPM里：给去噪结果加上随机采样噪声，生成 $x_{t-1}$，以增加多样性

**条件生成**

+ 问题：无法生成可控图像
+ 方法：文本作为模型输入，与图像进行交叉注意力

**隐空间扩散**

+ 问题：生成速度慢（本质是计算量大）
+ 方法：使用VAE，在隐空间中扩散

### 流匹配模型（Flow Matching, FM）

#### 刻画映射的其他方法

**扩散模型映射路径**
+ 逐步加入噪声，得到映射路径
+ 由于加噪过程的噪声是随机取样的，所以映射路径是弯曲、随机的

![alt text](img/FM-1.png)

**新思路**：
+ 将映射途经拆成若干线段之和
+ 计算：已知样本速度，计算每条线段，累加得到总路径

#### 流匹配模型原理

**向量场**
+ 已知状态和时间，样本在此时此处的速度向量，包括速度大小和方向
+ 同一 $t$ 下，每个坐标点预设一个速度向量，如$x_{0.5}$对应速度向量为$v_{0.5}$

**原理**
+ 从随机噪声，通过多步直线路径，生成图像
+ 与扩散模型类似，但不同状态的媒介不再是噪声，而是直线路径
+ 对于当前步的状态和时间，预测向量场，得到路径和下一步状态

![alt text](img/FM-2.png)

#### 流匹配训练过程

+ 随机采样噪声 $x_0$ 和样本 $x_1$
+ 通过 $x_t = (1-t)x_0 + tx_1$得到t时刻的理想状态
+ 根据$x_t$和$t$，预测此时的速度$v_{pred}$
+ 计算$v_{pred}$与真实$v=x_1-x_0$之间的L2损失

![alt text](img/FM-3.png)

#### 与扩散模型对比总结

+ 扩散模型
  + 生成图片：多步去除噪声
  + $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$
+ 流匹配
  + 生成图片：多步位移
  + $x_t = (1-t)x_0 + tx_1$
