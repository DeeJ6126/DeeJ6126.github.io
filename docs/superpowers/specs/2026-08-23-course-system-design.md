# Dee's Blog 课程系统设计

## 范围

本阶段交付可正式使用的 Astro 课程系统，而不是独立 HTML 演示。范围包括：

- 建立 Astro 静态站点基础与共享页面外壳；
- 实现课程长卷页与课程详情页；
- 迁移并整理现有生物科学、生物信息和人工智能笔记；
- 支持 Markdown、R Markdown 和 PDF 三类课程笔记；
- 支持 Markdown 图片、代码块和数学公式；
- 支持 PDF 页面内预览与原文件下载；
- 保留现有内容质量检查和资料扫描逻辑；
- 为项目页、关于页和正式转场保留扩展接口，但本阶段不实现它们。

正式转场不在本阶段实现。开始转场设计前，必须从 `Blue Sky.mp4` 的相关片段按每秒 8 至 12 帧提取密集序列，分析运动路径、节奏、缓动和元素重组方式。

## 信息架构

课程页是站点默认入口，按以下顺序形成连续长卷：

1. 生物科学：生物化学、生态学；
2. 生物信息：AnnData、R、Scanpy；
3. 人工智能：动手学深度学习、深度学习导论。

左侧透明导航固定显示三个学科。点击导航平滑滚动到对应区域；滚动进入区域时，当前学科自动变为深色，其他学科保持浅色。右上角的小搜索只按课程名称筛选当前课程长卷。

每门课程进入一个独立详情页。详情页只有两个内容区：

1. 课程感想；
2. 课程笔记。

## 内容模型

每门课程由一个课程 Markdown 文件描述。Front Matter 保存：

- `title`：课程名称；
- `slug`：稳定路由标识；
- `discipline`：`biology`、`bioinformatics` 或 `ai`；
- `order`：学科内排序；
- `cover`：课程封面；
- `summary`：课程长卷中的简短说明；
- `resourceCategory`：可选，对应现有 PDF 资料分类。

课程 Markdown 正文即“课程感想”。课程笔记是独立条目，类型为：

- `markdown`：由 `.md` 或 `.Rmd` 迁移而来；
- `pdf`：来自现有 `source/files/` 资料目录。

Markdown 笔记保存标题、所属课程、顺序和原始来源。PDF 标题和顺序继续复用 `source/_data/resources.yml`，不在课程文件中重复维护。

迁移器负责：

- 将 `.Rmd` 转成站点可渲染的 Markdown 副本；

- 保持来源文件不变，并允许重复运行而不产生重复内容。

## 课程详情页面

页面顶部沿用全站导航和“返回课程”。课程标题区包含学科标签、课程名称、摘要与封面。

“课程感想”以受限正文宽度和较大行距渲染 Markdown。它与视觉较强的标题区形成安静的阅读层。

“课程笔记”按顺序显示条目：

- PDF 条目提供“预览”和“下载”；
- Markdown 条目提供“阅读”和“收起”；
- 笔记条目使用原生 `details` 结构，JavaScript 只增强为同一时间展开一篇，避免页面同时出现多个大型阅读器；
- 展开 Markdown 后显示文章目录、正文、代码、公式和图片；
- 展开 PDF 后使用浏览器原生 PDF 阅读器；
- PDF 无法内嵌时显示明确错误，并保留“新窗口打开”和“下载”；
- 无笔记时显示简洁空状态，不渲染空白阅读器。

## 视觉规则

视觉沿用已经确认的 Blue Sky 几何简约方向：灰白纸张底、蓝色主视觉、少量青色与荧光绿强调、细线、方块、印刷颗粒和强排版。

课程长卷与详情页不使用圆角卡片、玻璃拟态或装饰性渐变。课程详情的正文、代码、图片和 PDF 必须优先保证可读性。页面以桌面端为主，移动端仅保证内容不溢出、导航可用和阅读功能可达。

## 构建架构

Astro 输出纯静态站点，继续部署到 GitHub Pages。课程和 Markdown 笔记使用 Astro 内容集合进行 schema 校验与静态路由生成。

现有 `lib/`、`scripts/`、`tools/` 和 `test/` 不直接删除。可复用的资源扫描和内容检查逻辑继续作为唯一数据解释入口；Hexo 专用注册层在后续迁移完成前保留。

`source/files/` 继续作为 PDF 的唯一源目录。Astro 的开发与构建流程通过项目级静态资源适配器提供 `/files/` 路径，不在仓库中维护第二份 PDF 副本。

浏览器端 JavaScript 只负责：

- 学科滚动高亮；
- 课程名称筛选；
- Markdown/PDF 阅读器的互斥展开增强；
- 阅读器错误与降级状态。

## 错误处理

以下问题在构建时失败并给出具体文件路径：

- 课程字段缺失或重复 slug；
- 笔记引用不存在的课程；
- Markdown/R Markdown 引用缺失图片；
- PDF 元数据引用不存在文件；
- 路径仅存在大小写差异；
- 迁移来源文件不存在。

浏览器运行时错误不得破坏基础访问。JavaScript 失效时，原生 `details` 仍可展开 Markdown，PDF 仍可通过链接打开或下载。

## 验证

自动化验证覆盖：

- 课程 schema、排序和路由；
- 三个学科与七门课程的内容映射；
- 外部 Markdown/R Markdown 迁移的幂等性；
- 图片依赖复制与缺图报告；
- R 代码围栏转换；
- PDF 与 Markdown 笔记类型；
- 课程名筛选；
- Astro 静态构建输出。

浏览器验证覆盖：

- 课程长卷滚动与左侧高亮；
- 生物化学 PDF 的预览、收起和下载；
- R Markdown 的阅读、代码和图片；
- 课程感想与课程笔记的长内容布局；
- 桌面端主要视口和移动端基本回退；
- 无控制台错误、无内容重叠、无断裂资源。

完成后至少运行：

```bash
npm test
npm run check
npm run build
```
