# 选择判断

**脊索动物**门（含**圆口纲**）
- **原索动物**由哪些类群构成（2次）
  - **答案：****尾索动物亚门**和**头索动物亚门**
  - 要点
    - 原索动物=尾索+头索，为低等脊索动物（无脊椎脊索动物），有脊索无脊柱
  - 出处：第11章 **脊索动物**门，第62页
- 以下哪个属于**尾索动物**（**海鞘**）（2次）
  - **答案：****海鞘**
  - 要点
    - 尾索动物成体被囊包被（被囊动物），幼体有脊索和背神经管，行逆行变态
    - 头索动物（文昌鱼）终生保留脊索
  - 出处：第11章 **脊索动物**门，第64-78页
- 以下哪种动物是雌雄同体（**海鞘** / **文昌鱼** / **七鳃鳗** / **盲鳗**）
  - **答案：****海鞘**和**盲鳗**均为雌雄同体（**海鞘**为雌雄同体，**盲鳗**也是雌雄同体；**文昌鱼**为雌雄异体；**七鳃鳗**为雌雄异体）
  - 要点
    - 海鞘和盲鳗雌雄同体，文昌鱼和七鳃鳗雌雄异体
  - 出处：第11章 **脊索动物**门，第72页/第89页/第136页
- 下列动物中，属于**尾索动物**的是
  - **答案：****尾索动物**包括：**尾海鞘纲**（如住囊虫）、**海鞘纲**（如**海鞘**）、**樽海鞘纲**（如樽**海鞘**）
  - 要点
    - 尾索动物分3纲：尾海鞘纲（蝌蚪形游泳）、海鞘纲（固着被囊厚）、樽海鞘纲（自由被囊薄）
    - 幼体有脊索和背神经管，成体逆行变态
  - 出处：第11章 **脊索动物**门，第64-79页
- **脊椎动物**与无**脊椎动物**的分界是
  - **答案：** 脊椎（脊柱/脊椎骨）的出现
  - 要点
    - 原索动物有脊索无脊柱，脊椎动物以脊柱代替脊索
    - 分界在是否出现脊椎骨
  - 出处：第11章 **脊索动物**门，第62页/第107页
- 所有**脊索动物**都是闭管循环系统（判断）
  - **答案：** 错误
  - 要点
    - 尾索亚门有特殊的循环机制
  - 出处：第11章 **脊索动物**门，第70页/第87页

鱼纲
- 鱼的椎体类型（**双凹型**）（2次）
  - **答案：****双凹型**
  - 要点
    - 鱼类和有尾两栖类椎体为双凹型
    - 相邻椎体间留存残余脊索
  - 出处：第12章 鱼纲，第29页/第17章 比较解剖，第59页
- 鱼的心脏中流动的是何种血液（缺氧血）（2次）
  - **答案：** 缺氧血（乏氧血/静脉血）
  - 要点
    - 鱼类单循环，心脏位于静脉端，泵出缺氧血经鳃氧合后运全身
  - 出处：第12章 鱼纲，第52-53页
- 鱼分为哪几个部分（头、躯干、尾）
  - **答案：** 头、躯干、尾
  - 要点
    - 鱼类头骨与躯椎间无颈部
    - 头部不能转动
  - 出处：第12章 鱼纲，第15页
- **发电器官**来源于（肌肉 / 皮肤腺），代表物种（**电鳗** / **电鲇**）
  - **答案：** 来源：肌肉（多数鱼类）或真皮腺（少数鱼类）；代表物种：**电鳗**（肌肉来源）、**电鲇**（真皮腺来源）
  - 要点
    - 电鳐和电鳗发电器由肌肉演变
    - 电鲇由真皮腺特化
  - 出处：第12章 鱼纲，第33页
- **红腺**与**卵圆窗**的功能
  - **答案：** 调节**鳔**内气体（气体分泌与吸收）
  - 要点
    - 闭鳔类无鳔管，通过红腺分泌气体、卵圆窗吸收气体
    - 管鳔类有鳔管连食道
  - 出处：第12章 鱼纲，第49页
- 鱼类的皮肤衍生物包括
  - **答案：** 鳞片和粘液腺
  - 要点
    - 鳞片分盾鳞（软骨鱼）、硬鳞（原始硬骨鱼）、骨鳞（圆鳞/栉鳞）
    - 粘液腺为单细胞粘液腺
  - 出处：第12章 鱼纲，第19-23页
- 鱼类用口进水、鳃出水，而**七鳃鳗**的进水和出水均通过鳃孔（判断）
  - **答案：** 正确
  - 要点
    - 七鳃鳗寄生时水从外鳃孔出入
    - 自由生活时仍可从口进水
  - 出处：第11章 **脊索动物**门，第134-135页
- 鱼类心脏内是乏氧血（判断）（2次）
  - **答案：** 正确
  - 要点
    - 鱼类单循环，心脏位于静脉端，心脏内全为缺氧血
  - 出处：第12章 鱼纲，第52-53页
- **角质鳞**与**盾鳞**、牙齿等的区别
  - **答案：****角质鳞**为**表皮衍生物**（羊膜类），**盾鳞**为**真皮衍生物**（**软骨鱼类**），牙齿为外胚层+中胚层共同形成
  - 要点
    - 表皮衍生物包括角质鳞、角质齿、爪/蹄、羽、毛、表皮角
    - 真皮衍生物包括盾鳞、骨质鳞、骨板、实角
  - 出处：第17章 比较解剖，第50-51页/第12章 鱼纲，第22页

**两栖纲**
- 只有圆口类和鱼类有鳃（判断）
  - **答案：** 错误
  - 要点
    - 两栖类幼体（蝌蚪）也有鳃
    - 高等种类（爬行类以上）胚胎期具咽鳃裂、成体用肺
  - 出处：第13章 **两栖纲**，第12页
- **两栖动物**哪对**动脉弓**汇入背大动脉
  - **答案：** 第4对**动脉弓**（**体动脉弓**）
  - 要点
    - 第3对→颈动脉弓
    - 第4对→体动脉弓（汇合为背大动脉）
    - 第6对→肺皮动脉弓
  - 出处：第13章 **两栖纲**，第49-50页/第17章 比较解剖，第103页
- **两栖动物**的皮肤腺类型
  - **答案：** 粘液腺和**毒腺**（均为多细胞泡状腺）
  - 要点
    - 两栖类多细胞腺体埋于真皮（鱼类为单细胞腺）
    - 爬行类干燥无腺体
    - 哺乳类有皮脂腺/汗腺/乳腺/味腺
  - 出处：第13章 **两栖纲**，第25-27页

**爬行纲**
- **寰椎**、**枢椎**是哪类动物的标志（有**羊膜卵**的类群/爬行类以上）
  - **答案：** 爬行类及以上（有**羊膜卵**的类群）的标志
  - 要点
    - 两栖类已有寰椎但无枢椎特化
    - 完整寰椎+枢椎从爬行类开始
  - 出处：第14章 **爬行纲**，第25页
- **颊窝**的功能
  - **答案：** 红外线感受（热能感受/热定位）
  - 要点
    - 颊窝是蝮亚科蛇类的红外线感受器（非嗅觉器官）
    - 蟒蛇唇窝类似
  - 出处：第14章 **爬行纲**，第60页
- **次生腭**的功能
  - **答案：** 将口腔分为上下两层：上层为嗅觉和呼吸通路，下层为固定的口腔
  - 要点
    - 次生腭出现于羊膜动物（爬行类以上），使呼吸和进食可同时进行
  - 出处：第14章 **爬行纲**，第23页
- 爬行类动物首次出现**新脑皮**（判断/选择）
  - **答案：** 正确（爬行类首次出现**新脑皮**）
  - 要点
    - 脑皮进化：古脑皮（鱼类）→原脑皮（肺鱼、两栖类）→新脑皮（爬行类开始，哺乳类高度发达）
  - 出处：第14章 **爬行纲**，第53页/第17章 比较解剖，第114页
- 排泄物类型：尿酸 / 尿素的分布
  - **答案：** 鱼类：氨；两栖类：尿素；爬行类：尿酸；鸟类：尿酸；哺乳类：尿素
  - 要点
    - 氨需大量水（水生鱼类）
    - 尿素需水量中等（两栖类、哺乳类）
    - 尿酸毒性低不溶水（爬行类、鸟类适应干旱环境）
  - 出处：第14章 **爬行纲**，第51页/第16章 哺乳纲，第5页

鸟纲
- 哪个类群没有膀胱
  - **答案：** 鸟类
  - 要点
    - 鸟类无膀胱（适应飞翔）
    - 尿由尿酸组成
    - 水分可重吸收
  - 出处：第15章 鸟纲，第53页
- 有**龙骨突**但不会飞的鸟（非洲鸵鸟 / 鸸鹋 / 帝企鹅 / 长尾雉）
  - **答案：** 帝企鹅
  - 要点
    - 企鹅总目有龙骨突但不会飞（潜水）
    - 平胸总目（鸵鸟、鸸鹋）无龙骨突不会飞
    - 突胸总目有龙骨突能飞
  - 出处：第15章 鸟纲，第75-78页
- 以下哪种鸟没有羽区和裸区的区分（2次）
  - **答案：****平胸总目**（如非洲鸵鸟、鸸鹋等）和**企鹅总目**
  - 要点
    - 突胸总目有羽区/裸区之分以利肌肉收缩
    - 平胸总目和企鹅总目羽毛均匀分布无裸区
  - 出处：第15章 鸟纲，第75页/第78页
- 哪种羽毛没有**羽小钩**
  - **答案：****绒羽**和**纤羽**
  - 要点
    - 正羽有羽小钩形成连续羽片（飞行）
    - 绒羽无小钩（保温）
    - 纤羽如毛发（触觉）
  - 出处：第15章 鸟纲，第24-27页
- 属于**雀形目**的鸟（夜鹭 / 白鹭 / 小鸊鷉 / 鹎）
  - **答案：** 鹎（如领雀嘴鹎）
  - 要点
    - 雀形目为最大目，鸣禽属此目鸣管发达
    - 夜鹭/白鹭为鹈形目，小鸊鷉为鸊鷉目
  - 出处：第15章 鸟纲，第124-125页
- **愈合荐骨**由哪些骨骼愈合而成
  - **答案：** 少数胸椎、腰椎、荐椎和部分尾椎
  - 要点
    - 愈合荐骨（综荐骨）与腰带愈合形成开放式骨盆
    - 后部尾椎退化为尾综骨
  - 出处：第15章 鸟纲，第34页
- 所有鸟类都有**尾脂腺**（判断）
  - **答案：** 错误
  - 要点
    - 部分鸟类尾脂腺退化或缺失（鸵鸟、鸸鹋、部分鹦鹉和鸽类）
    - 水鸟尾脂腺较发达
  - 出处：第15章 鸟纲，第20页

哺乳纲
- **原兽亚纲**与**真兽亚纲**的主要区别
  - **答案：****原兽亚纲**卵生，**真兽亚纲**胎生（具真正**胎盘**）
  - 要点
    - 原兽亚纲卵生、具泄殖腔、无乳头、无胼胝体、体温低
    - 真兽亚纲胎生、有乳头、有胼胝体
    - 后兽亚纲（有袋类）胎生无真胎盘、有育儿袋
  - 出处：第16章 哺乳纲，第93页/第99页
- 以下哪个属于**后兽亚纲**
  - **答案：** 大袋鼠等有袋类
  - 要点
    - 后兽亚纲胎生无真正胎盘，有育儿袋和异型齿，无胼胝体，主要分布于澳洲
  - 出处：第16章 哺乳纲，第96-98页
- 哺乳动物胚胎发育时期的肾脏依次是
  - **答案：****前肾**→ **中肾**→ **后肾**
  - 要点
    - 羊膜类经历前肾→中肾→后肾三阶段
    - 无羊膜类仅前肾（胚胎）和背肾（成体）两阶段
  - 出处：第17章 比较解剖，第81-88页
- 哺乳动物和鸟类的起源分别来自
  - **答案：** 哺乳类起源于爬行类（兽孔类**爬行动物**），鸟类起源于爬行类（初龙类/恐龙）
  - 要点
    - 哺乳类由盘龙类→兽孔类→兽齿类进化
    - 鸟类由恐龙类进化，始祖鸟为过渡类型
  - 出处：第16章 哺乳纲，第160页/第15章 鸟纲，第23页
- 人的脊椎属于哪种类型（前凹 / 双凹 / 后凹）
  - **答案：****双平型**
  - 要点
    - 哺乳类双平型椎体，具椎间盘缓冲震动，进化程度最高
  - 出处：第16章 哺乳纲，第31页/第17章 比较解剖，第59页
- 牙齿由什么胚层发育而来
  - **答案：** 外胚层和中胚层共同形成
  - 要点
    - 釉质由外胚层形成，齿质由中胚层形成
    - 牙齿与软骨鱼的盾鳞同源
  - 出处：第17章 比较解剖，第74页
- 哪种是真皮的衍生物（鹿角）（2次）
  - **答案：** 鹿角（实角）
  - 要点
    - 实角（鹿角）为真皮骨化形成、每年脱换
    - 洞角（牛角）为表皮角质鞘+真皮骨质芯
  - 出处：第17章 比较解剖，第51页

比较解剖 / 综合
- 吴氏管（**中肾管**）的功能
  - **答案：** 羊膜类（鸟类）：仅输精（输精管）
  - 要点
    - 吴氏管（中肾管）在无羊膜类输尿兼输精，羊膜类雄性仅输精
    - 牟勒氏管在雌性发育为输卵管
  - 出处：第17章 比较解剖，第94页
- 排泄物类型与各类群对应（尿酸 / 尿素 / 氨）
  - **答案：** 鱼类排泄氨，两栖类和哺乳类排泄尿素，爬行类和鸟类排泄尿酸
  - 要点
    - 氨需大量水（水生鱼类）
    - 尿素需水量中等（两栖+哺乳）
    - 尿酸毒性低不溶水（爬行+鸟适应干旱）
  - 出处：第14章 **爬行纲**，第51页/第16章 哺乳纲，第5页/第17章 比较解剖，第5页
- 皮肤衍生物的比较：**角质鳞**、**盾鳞**、羽毛、毛发的来源与分布
  - **答案**
    - **角质鳞**
      - **表皮衍生物**
      - 羊膜类
    - **盾鳞**
      - **真皮衍生物**
      - **软骨鱼类**
    - 羽毛
      - **表皮衍生物**
      - 鸟类
    - 毛发
      - **表皮衍生物**
      - 哺乳类
  - 要点
    - 表皮衍生物：角质齿/鳞、爪/蹄、羽、毛、表皮角
    - 真皮衍生物：盾鳞、骨质鳞、骨板、实角
  - 出处：第17章 比较解剖，第50-51页
